# 오토블로그 AI — 개인정보 처리방침

**서비스명:** 오토블로그 AI (AutoBlog AI)  
**운영자:** [운영자 상호/이름 입력]

## 1. 수집하는 개인정보

오토블로그 AI는 별도 회원가입 웹사이트 없이 Chrome 확장 프로그램과 API 서버로 서비스를 제공합니다.

| 항목 | 수집 경로 | 목적 | 보관 |
|------|-----------|------|------|
| 라이선스 키 | 사용자 입력 | 구독 인증 | 사용자 브라우저 로컬 저장 + 서버 DB |
| 현장 작업 정보 (위치, 문제, 해결 내용 등) | 사용자 입력 | AI 블로그 글 생성 | AI API 호출 시에만 전송, 서버에 장기 저장하지 않음 |
| API 요청 로그 (키, 시간, 성공 여부) | 자동 | 사용량 한도·운영 | 서버 DB |

## 2. 수집하지 않는 정보

- 이름, 주민등록번호, 위치 GPS 좌표
- 네이버 계정 ID·비밀번호
- 결제 카드 정보 (무통장 입금만 사용)

## 3. 개인정보의 이용

- 라이선스 유효성 검증 및 사용량 한도 관리
- AI 블로그 초안 생성 (Google Gemini, OpenAI API)
- 서비스 운영 및 고객 문의 대응

## 4. 제3자 제공

AI 글 생성을 위해 아래 서비스에 현장 입력 텍스트가 전송됩니다.

| 제공받는 자 | 제공 항목 | 목적 |
|-------------|-----------|------|
| Google (Gemini API) | 현장 입력 텍스트 | AI 글 생성 |
| OpenAI (GPT API) | 현장 입력 텍스트 | AI 글 생성 (Fallback) |

위 외 제3자에게 개인정보를 판매하거나 제공하지 않습니다.

## 5. 보관 기간

| 항목 | 기간 |
|------|------|
| 라이선스 정보 | 구독 만료 후 1년 (또는 관련 법령에 따름) |
| API 요청 로그 | 90일 |
| AI 생성 요청 본문 | 서버에 저장하지 않음 |

## 6. 사용자 권리

- 라이선스 키 삭제: Chrome 확장 프로그램에서 키 입력란 비우기 + 브라우저 저장 데이터 삭제
- 구독 해지·환불: 운영자에게 연락 ([연락처 입력])
- 정보 삭제 요청: [연락처 입력]으로 요청

## 7. 보안

- API 키는 서버 환경변수로 관리
- 라이선스 검증은 서버에서 수행
- HTTPS 통신 (프로덕션 배포 시)

## 8. 아동 개인정보

본 서비스는 만 14세 미만을 대상으로 하지 않습니다.

## 9. 방침 변경

변경 시 Chrome Web Store 페이지 또는 확장 프로그램 내 안내를 통해 공지합니다.
