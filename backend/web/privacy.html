오토블로그 AI 개인정보 처리방침

최종 수정일: 2026년 9월 15일 · 운영자: ACROSSTOOL

1. 수집하는 개인정보

오토블로그 AI는 별도 회원가입 없이 모바일 웹과 Chrome 확장, API 서버로 서비스를 제공합니다.

항목수집 경로목적보관
라이선스 키사용자 입력구독 인증브라우저 로컬 + 서버 DB
현장 작업 정보사용자 입력AI 초안 생성생성 시에만 전송, 서버에 장기 저장하지 않음
API 요청 로그자동한도·운영서버 DB

2. 수집하지 않는 정보

  • 이름, 주민등록번호, GPS 좌표
  • 네이버 계정 아이디·비밀번호
  • 결제 카드 정보 (무통장 입금만 사용)

3. 이용 목적

  • 라이선스 확인 및 사용량 한도 관리
  • AI 초안 생성 (Google Gemini, OpenAI)
  • 고객 문의 대응

4. 제3자 제공

글 생성을 위해 현장 입력 텍스트가 Google(Gemini) 및 OpenAI(GPT, 예비)에 전송됩니다. 그 외 제3자에게 판매하거나 제공하지 않습니다.

5. 보관 기간

  • 라이선스 정보: 구독 만료 후 1년 또는 관련 법령
  • API 요청 로그: 90일
  • AI 생성 요청 본문: 서버에 저장하지 않음

6. 사용자 권리

라이선스 키는 화면에서 지우고 브라우저 저장 데이터를 삭제할 수 있습니다. 해지·환불·삭제 요청은 아래 문의처로 연락해 주세요.

7. 보안

API 키는 서버 환경변수로 관리하며, 라이선스 검증은 서버에서 수행합니다. 프로덕션은 HTTPS를 사용합니다.

8. 아동 개인정보

만 14세 미만을 대상으로 하지 않습니다.

9. 방침 변경

변경 시 본 페이지와 서비스 화면에서 안내합니다.
